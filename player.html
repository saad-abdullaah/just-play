Just-Play


A lightweight music player built with JavaScript


Just-Play is a custom music player built from scratch using HTML, CSS, and JavaScript. Songs are stored in a structured array — each holding a title, artist, cover image, and audio source — and rendered dynamically into a playlist. The player handles play/pause, next/previous track, and a live progress bar with real-time duration tracking.
Beyond basic playback, Just-Play supports queue management, letting users line up songs to play next, along with a custom playlist system where users can create playlists on the fly and organize their favorite tracks into them.
